# Backend

This backend provides JWT-based authentication using Express.

## Structure

- `src/config` - configuration files
- `src/controllers` - route controllers
- `src/middleware` - middleware such as JWT validation
- `src/models` - data models or persistence layer
- `src/routes` - route definitions

## Run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   npm start
   ```
